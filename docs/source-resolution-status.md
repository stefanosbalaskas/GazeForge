# Source-resolution status

This page is generated during the documentation build from the integrity-checked
`source-resolution-status-v1` records in `validation/protocols`.

The generated site presents **governance status, not performance evidence**. Individual checkpoints
may reference separately frozen empirical source evidence when that evidence has actually been
created, but source-resolution status does not by itself establish model performance, independent
human-human reliability, source-audit readiness, analysis or redistribution rights, native GP3
validity, or Frozen Evidence publication.
