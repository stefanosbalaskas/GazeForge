# GazeForge

GazeForge provides auditable AI infrastructure for eye-tracking analysis.

The package is organised around five layers:

1. **Schema** — vendor-neutral canonical gaze samples.
2. **AI/QC** — anomaly scoring and trainable event models.
3. **Semantic AOIs** — computer-vision proposals plus human review.
4. **Sequences** — semantic scanpaths, motifs, embeddings, similarity, clustering.
5. **Audit** — fingerprints, provenance records, and model cards.

The package is currently alpha software. Confirmatory use requires task-specific validation.
