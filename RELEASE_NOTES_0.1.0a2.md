# GazeForge 0.1.0a2

This is the second public alpha release of GazeForge.

## Highlights

- Expanded fail-closed source, protocol, authority, lineage, Frozen Evidence, and scientific-review contracts.
- Expanded VISUS source-audit, protocol-validation, authority-transition, scientific-review, and human-agreement infrastructure.
- Substantially expanded meaningful statement and branch coverage.
- Improved provenance, documentation, methodological guidance, and release qualification.

## Scientific boundary

0.1.0a2 remains an alpha release.
This release is not native GP3/60 Hz device validation.
Gaze-in-the-Wild infrastructure does **not** establish exact-byte acquisition by itself.
Participant-disjoint model validation remains bounded by the applicable frozen evidence.
A human reference stream is not automatically ground truth.
A stable scientific release remains gated on the remaining native-device, cross-dataset, dynamic-detection/tracking, and API-stability work.
